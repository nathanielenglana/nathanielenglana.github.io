Content and design system

NF.ai is a business project of mine: AI assistants that answer WhatsApp enquiries and take bookings for small businesses. I wanted its social posts to look like one brand without designing each one by hand, so I wrote the brand down as a brief, had Claude Design build a full design system from it, and set up a small content pipeline around it in Claude Code.

What is in it

  • Tokens for colour, type, spacing, shape and motion, with semantic names on top so a dark surface is one class.
  • Components for buttons, cards, forms, alerts, dialogs and tabs, each with a short prompt file that tells an AI tool how to use it.
  • Three brand components that carry the look. ModularField draws the geometric artwork on a grid, and MonoLabel and StatBlock keep the monospace font to numbers and timestamps.
  • Two UI kits: 1080px social posts in five formats, and the sections of a marketing website.
  • Templates for a landing page and two kinds of social post, ready to copy and edit.

The system has two registers. The approachable one uses the lighter blues, few shapes and rounder corners, for first-touch posts. The technical one uses the dark blues, denser artwork and sharper corners, for case studies and how-it-works content. Both use the same shapes and the same rules.

The rules

The brief is the governing document. It holds the positioning, the voice rules, the logo rules, colour, type, spacing, grid and a shape vocabulary, and the design system follows it wherever the two disagree.

  • Colour is a single blue ramp of seven steps. There is no second hue and no grey family.
  • The brief gives the WCAG contrast ratio for each text and background pairing in the ramp, and says which pairs are safe for body text, which only for large text, and which never.
  • Type is Geist on a modular scale, with one set of sizes for web and a larger set for a 1080px social canvas.
  • Spacing snaps to an 8px base unit.
  • Text always sits in a flat clear zone with no shape edges crossing it.
  • Every social post is checked at feed thumbnail size. If the headline stops reading at 110px, the post isn't finished.

The pipeline

1. /create-content

Takes a topic and a post type and writes a copy brief: the key message, a headline with alternates, a subhead, the audience and the tone.

2. /create-creative

Reads that brief and packages the copy with the platform and format only. It adds no visual or layout direction.

3. Design

The packaged copy goes to Claude Design together with the design system, which decides the composition, the shapes and the colour.

What I learned

The first round of posts followed the brief and still came out wrong. The background artwork was as loud as the headline, and the shapes all carried the same weight. The brief had preferences in it but no hierarchy rules.

I rewrote it with a checklist to run before accepting any piece: where the eye lands first, what order it moves in, whether the size steps between tiers are large enough, and whether there is one emphasis zone. Each failure that had already happened once is listed by name.

I also tested how much direction to give. The design system plus the copy and the format produced good output. When I added my own visual direction on top, the results got worse, so the creative step now leaves it out on purpose.
