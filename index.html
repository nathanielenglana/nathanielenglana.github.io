How this site is tracked

This site is also my practice ground for analytics. Every page carries a Google Analytics 4 tag with enhanced measurement on, so page views, scrolls, outbound clicks and file downloads are recorded.

On top of that I send three custom events: resume_download when someone opens the resume, contact_click for the email and LinkedIn links, and project_view with the project name on each project page. contact_click is marked as the key event.

The site is verified in Google Search Console with a sitemap submitted, and the GA4 data feeds a Looker Studio report with users over time, top pages and event counts.
